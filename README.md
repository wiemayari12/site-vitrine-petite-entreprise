# Site web de présentation d'une petite entreprise

## À propos du projet
Projet universitaire réalisé en groupe dans le cadre de la matière Programmation Web à l'ESEN.

## Objectif
Créer un site web simple permettant à une petite entreprise de présenter ses activités, ses services et ses coordonnées.

## Fonctionnalités prévues
- Page d'accueil
- Présentation de l'entreprise
- Présentation des services
- Page de contact

## Technologies
À compléter selon les technologies utilisées dans le projet.

Projet en cours de réalisation.
